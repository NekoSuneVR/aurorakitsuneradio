# Paper audio playback via OpenAudioMc
Install and configure OpenAudioMc first (players connect to its web audio session). This plugin does not open raw stream URLs in chat anymore: `/radio <query>`, then `/radio play <number>` tells OpenAudioMc to play the stream privately for that player, `/radio stop` stops it. No player needs to install Fabric/Forge for this mode, but an OpenAudioMc browser session is still required. The source targets OpenAudioMc API 6.10.16 and has **not** been compiled or validated on a live server; API signatures may need adjustment. MCJukebox can be considered later as an alternative adapter.
